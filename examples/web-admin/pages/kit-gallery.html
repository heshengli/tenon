下拉选择tn-data="select"

页面写的就是原生 <select>，控件把它换成可搜索面板， 选中状态同步回原生节点 —— 表单序列化、校验、老代码里的 sel.value 全都不用改。

级联选择tn-data="cascader"

层级用 data-parent 描述（嵌套 optgroup 会被 HTML 解析器拆平）。 被引用的节点是分叉，点了下钻；只有叶子可选。

文件选择tn-data="upload"

页面写的就是原生 <input type="file">：点击或拖拽都能选，列表可删单个文件， 选中的文件同步回原生 input —— new FormData(form) 照旧拿得到。 控件只管「选」，不管「传」：上传进度、分片、直传都归宿主。
